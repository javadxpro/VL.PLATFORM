Volexturn — کوتاه‌ترین مسیر اجرا
================================

این فایل فقط چک‌لیست است؛ توضیح کامل: README.md (دسکتاپ/سرور) و docs/TERMUX.md (گوشی).
⚠️ شرط قانونی استفاده در LICENSE است: مجوزی داده نشده — اجرا/کپی/توزیع فقط با اجازهٔ کتبی.

۱) لینوکس / مک / ویندوز (دسکتاپ)
---------------------------------
  git clone https://github.com/javadxpro/VL.PLATFORM.git
  cd VL.PLATFORM
  python3 -m venv .venv && . .venv/bin/activate      # ویندوز: .venv\Scripts\activate
  pip install -r requirements.txt
  python3 -m backend doctor
  python3 -m backend create-admin -u root -p 'یک-رمز-بلند'
  bash ./run.sh                                       # http://localhost:5000

۲) Termux روی اندروید (gevent لازم ندارد)
-----------------------------------------
  pkg update -y && pkg install -y python git
  git clone https://github.com/javadxpro/VL.PLATFORM.git && cd VL.PLATFORM
  bash ./termux.sh install                              # pip install -r requirements-core.txt + migrate + doctor
  python3 -m backend create-admin -u root -p 'یک-رمز-بلند'
  termux-wake-lock
  bash ./termux.sh run                                  # آدرس LAN را چاپ می‌کند

  نکته: در Termux `pip install -r requirements.txt` نصب نمی‌شود (gevent build نمی‌شود)؛
  core را نصب کن. بقیهٔ دستگاه‌ها با http://<IP-گوشی>:5000 (مودم AP-isolation نداشته باشد).

۳) proot-distro (اوبونتو داخل اندروید، اگر apt لازم داری)
----------------------------------------------------------
  pkg install -y proot-distro && proot-distro install ubuntu
  proot-distro login ubuntu
  apt update && apt install -y python3 python3-pip git
  git clone https://github.com/javadxpro/VL.PLATFORM.git && cd VL.PLATFORM
  pip install --break-system-packages -r requirements-core.txt
  python3 -m backend doctor && bash ./run.sh

۴) عیب‌یابی یک‌خطی
------------------
  python3 -m backend doctor --json | python3 -m json.tool     # همه‌چیز از schema تا سقف آپلودها
  python3 -m backend routes --filter stories                   # مسیرهای واقعی سرور
  برای خودت روی LAN: VOLEXTURN_DEBUG=1 bash ./run.sh
