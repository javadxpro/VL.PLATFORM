# 🖥️ Local_Network — Volexturn Super-App v3.0 (Public)

یک سوپر‌اپلیکیشن **آفلاین و شبکه محلی (LAN)** با تجربه‌ی **تلگرام + اینستاگرام + یوتیوب** — چت شخصی و گروهی، شبکه اجتماعی کامل و ویدیو — بدون نیاز به اینترنت و با امنیت واقعی.

🇮🇷 پروژه ایرانی | ✅ آزادانه و رایگان | 🔒 نسخه Public v3.0.0

---

## 🆕 تازه‌های نسخه 3.0

- 👥 **گروه‌ها:** ساخت گروه، افزودن/حذف عضو، چت گروهی زنده، خروج/حذف گروه، بج خوانده‌نشده گروه
- ↪️ **هدایت پیام** به چند مخاطب و گروه هم‌زمان (با لیبل «هدایت‌شده»)
- 🖼️ **محدودیت هوشمند:** عکس ۵MB با **فشرده‌سازی خودکار** (Canvas)، فیلم ۱۰MB، فایل ۵۰MB
- 🔐 **پروتکل‌های امنیتی:**
  - رمزها با **PBKDF2-SHA256** (۱۰۰,۰۰۰ تکرار + Salt) هش می‌شوند — مهاجرت خودکار رمزهای قدیمی
  - **توکن نشست** برای همه API ها (Bearer Token) + پاسخ بدون رمز عبور
  - API های ادمین فقط با نقش ادمین (403 برای بقیه)
  - **Rate-limit** روی ورود/ثبت‌نام (ضد Brute-force)
  - هدرهای امنیتی: CSP، nosniff، Referrer-Policy، Permissions-Policy
  - اعتبارسنجی ورودی + جلوگیری از جعل هویت فرستنده
- 🏭 **نسخه Publish:** ترمینال توسعه حذف، دیباگ خاموش، اجرای پایدار

## ✨ ویژگی‌ها

### 💬 چت در سبک تلگرام
- پیام متنی، عکس، ویدیو، فایل و **پیام صوتی** — Real-time با Socket.IO
- ↩️ **ریپلای** به پیام خاص (با پرش به پیام اصلی)
- ✏️ **ویرایش پیام** + لیبل «ویرایش شده»
- 🗑️ حذف پیام برای هر دو طرف
- ✓✓ **تیک دیده‌شده**
- ⌨️ نشانگر **«در حال نوشتن...»** زنده
- 🔴 **بج پیام خوانده‌نشده** روی هر مخاطب
- 📌 **سنجاق پیام** مهم در بالای گفتگو
- 🔍 جستجو در تاریخچه گفتگو

### 📸 شبکه اجتماعی در سبک اینستاگرام
- ❤️ لایک پست با **انیمیشن دابل‌تپ**
- 💬 کامنت زیر پست‌ها
- 👤 **فالو/فالوور** + شمارنده و پروفایل عمومی
- #️⃣ **هشتگ‌های کلیک‌خور** و فیلتر اکسپلور با هشتگ
- 👀 **آمار بیننده‌های استوری** (چه کسی استوری من را دید؟)
- 🔔 **فید اعلان‌ها**: لایک، کامنت و فالو جدید — زنده
- استوری ۲۴ ساعته با حذف خودکار

### ▶️ ویدیو در سبک یوتیوب
- 👁️ **شمارنده بازدید** ویدیوها
- 🔥 تب **ترند** (مرتب‌سازی بر اساس لایک/کامنت/بازدید)
- 🕐 **تاریخچه تماشا**
- ✅ فید «دنبال‌شده‌ها»

### بقیه امکانات
- 🎙️ **ویس‌چت زنده گروهی** با WebRTC (P2P)
- 🎮 **بازی LAN:** ثبت و اشتراک هاست‌های بازی با کپی یک‌کلیکی IP
- 🛡️ **پنل مدیریت:** آمار زنده (لایک/کامنت/فالو/پیام/...)، مدیریت کاربران و پست‌ها
- 🌗 تم تاریک/روشن • 🔌 **کاملاً آفلاین** (فونت و Socket.IO لوکال) • 💾 SQLite • نشست پایدار بین رفرش‌ها

## 🚀 نصب و اجرا

### پیش‌نیازها
- Python 3.8+

### ۱️⃣ کلون مخزن
```bash
git clone https://github.com/javadxpro/Local_Network.git
cd Local_Network
```

### ۲️⃣ نصب وابستگی‌ها
```bash
pip install -r requirements.txt
```

### ۳️⃣ اجرای سرور
```bash
python3 server.py
```

### ۴️⃣ باز کردن در مرورگر
```
http://localhost:5000
```
از دستگاه‌های دیگر روی همان شبکه: `http://IP_سرور:5000`

## 🐛 حل مشکلات

**پورت اشغال است:** در انتهای `server.py` مقدار `port = 5000` را تغییر دهید.

**ویس‌چت کار نمی‌کند:** میکروفون باید به مرورگر اجازه داده شود؛ در شبکه‌های ایزوله، WebRTC از کاندیدهای محلی (host candidates) استفاده می‌کند.

**ویدیوی حجم بالا آپلود نمی‌شود:** محدودیت سرور ۵۰ مگابایت است (`MAX_CONTENT_LENGTH` در `server.py`).
